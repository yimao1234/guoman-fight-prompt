# 输入采集表

生成前先填这张表。**能从用户输入里推出的直接推，推不出的用右列兜底。** 只有题材完全无法判断时才回头问一句。

## 1. 必填槽位

| # | 槽位 | 说明 | 兜底值 |
|---|---|---|---|
| 1 | **题材 / 世界观** | 古武、仙侠、现代都市、科幻、赛博、校园 | 东方残破古战场 |
| 2 | **战场** | 地点 + 空间结构 + 天气 + 光源 | 按 `06-genre-shift.md` 自动生成 |
| 3 | **角色 A** | 称呼 + 服装材质配色 + 武器 | 若用户只给一人，生成"镜像对手" |
| 4 | **角色 B** | 同上 | 同上 |
| 5 | **气场色（A / B）** | 必须对撞 | 从 `04-move-lexicon.md` §3 挑一组 |
| 6 | **特效粒子（A / B）** | 各自的标志性粒子 | 由题材 + 气场色推导 |
| 7 | **招式流派** | 剑 / 刀 / 伞 / 棍 / 拳 / 机甲 / 法术 | 由服装武器推断 |
| 8 | **镜数** | 10 / 12 / 14 | 12 |
| 9 | **收尾方式** | 残心入鞘 / 延迟爆碎 / 定格 / 反打 | 残心 + 延迟爆碎 |
| 10 | **情绪锚** | 第二个镜头那张脸的表情 | 邪魅一笑（反派先手）/ 眼神爆燃（正派逆袭） |

## 2. 可选项

| 槽位 | 说明 |
|---|---|
| 谁先手 | 决定镜头 1 的视角归属 |
| 胜负 | 单方压制 / 势均力敌 / 反杀 |
| 大招形态 | 法相 / 巨手 / 机神 / 剑气 / 拳罡 |
| 特殊约束 | 如"不出现血腥""必须出现某道具" |

## 3. 采集示例

**用户输入**：「帮我写一场赛博朋克风的打斗，一个义体刀客对上重装机甲」

**填充结果**：

| 槽位 | 填入 |
|---|---|
| 题材 | 赛博朋克 |
| 战场 | 霓虹雨夜的高架桥顶，全息广告糊成光斑，桥下是几十米落差的车流灯河 |
| 角色 A | 义体刀客（浸透雨水的黑色风衣、左臂外露铬合金液压管，背负单分子太刀） |
| 角色 B | 重装机甲（哑光军绿装甲布满弹痕，手持一体式液压重锤） |
| 气场色 | A＝品红数据流 + 青白离子火花 / B＝暗橙等离子雾 + 低频力场波纹 |
| 招式流派 | A＝单分子刀 + 义体格斗 / B＝液压重锤 + 装甲冲撞 |
| 镜数 | 12 |
| 收尾 | 残心（单分子刀滑入背部刀鞘）+ 延迟爆碎（机甲沿斜线裂开） |
| 情绪锚 | 刀客在雨水里抬眼的机械瞳孔收缩 |

→ 直接进入 SKILL.md 的 Step 1。

## 4. 追问触发条件

只有在以下情况才停下来问：

- 用户只说「写个打斗」，连题材倾向都没有 → 问一句「古武 / 仙侠 / 科幻 / 现代，哪个方向？」
- 用户给了角色但要求"用 XX 的风格" → 询问 XX 是否指某个具体作品（避免直接复刻版权作品）

**其余情况一律先出稿，再让用户改。** 出稿比提问快。
