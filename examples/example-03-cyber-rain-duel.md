# 示例 03 · 赛博朋克 · 霓虹雨夜桥顶

> **验证目的**：证明这套引擎能从「古武水墨」整体位移到「赛博机甲」，骨架与打击感完全不变。
> **版式**：B（带时长）
> **镜数**：12
> **输入**：「写一场赛博朋克风的打斗，义体刀客对上重装机甲」

## 成品

8K 3D CG 写实，PBR 物理材质，16:9 画幅，60fps，【霓虹雨夜的高架桥顶，桥面裂缝里持续冒出白色蒸汽，两侧是几十米落差的湍急车流灯河，全息广告牌在雨幕中糊成大面积色块】，院线电影级色彩分级；义体液压管外露的金属接缝、皮肤毛孔与缝合疤痕、湿透发丝成缕贴在额角、雨水沿铬合金面滑落超写实，布料动力学真实，风衣下摆随高速位移呈撕裂状翻卷；【义体刀客（浸透雨水的黑色风衣，左臂整段外露铬合金液压管，背负单分子太刀）】周身萦绕【死死贴附在义体接缝与刀脊上流窜的品红数据流与青白离子火花】，【重装机甲（哑光军绿装甲布满弹痕与锈斑，手持一体式液压重锤）】周身萦绕【从装甲缝隙间持续喷涌的暗橙等离子雾与低频震颤的力场波纹】；人物绝对零站桩，每击皆在超高速闪转腾挪与地形穿梭中完成，拖拽极浓的霓虹全息残影；全招式叠加像素化墨迹扩散与离子碎屑，无悬浮光污染；全程强动态模糊 + Time Ramp（快慢镜头结合）；兵刃与肢体碰撞强制匹配三级固定特效：轻碰撞 = 等离子黑白冲击帧 + 0.05s 抽帧 + 局部负片 + 轴向微甩，重碰撞 = 放射冲击帧 + 0.1s 抽帧 + 中心负片 + 受力猛沉 / 回弹 + 三层等离子爆炸，大招爆发 = 全屏冲击帧 + 0.15s 定格抽帧 + 全屏负片闪白 + 中心鱼眼畸变 + 强光泛光 (Bloom) + 环形冲击波；采用 3A 动作游戏惯性追尾机位，运镜必须伴随物理动作高频变焦变速；全程纯画面输出。

### [镜头1] 1.5s | 桥顶起手：贴地极速前推 ➡️ 越肩微距 ➡️ 180度横甩

【复合运镜】：镜头贴着桥面积水极速前推，蒸汽从画面下缘翻涌掠过镜头。在太刀出鞘瞬间抬升至越肩微距，随后伴随两人交错轨迹瞬间完成 180 度横向甩摇（Whip Pan）。

【极速动势与拆招】：刀客单膝压至桥面极限，义体右腿关节发出蓝色液压辉光，风衣下摆被风撕开成一面残旗。机甲双脚液压缸下沉，把整块钢筋混凝土踩出蛛网状裂纹。两人身位相差 12 米，气场光芒在雨幕中互相侵蚀，交界处的雨滴被离子化后蒸腾成白雾。

【锚定特效与碰撞】：无碰撞。品红数据流沿刀客脊椎一节节亮起，暗橙等离子雾自机甲肩甲缝隙喷出并被雨水压成向下翻卷的雾柱。

### [镜头2] 1s | 机械瞳孔：极速推镜面部快切

【复合运镜】：镜头上摇切至刀客面部，极速推镜至眼部特写，强行打断起手的静谧。

【极速动势与拆招】：刀客微微垂首，雨水沿义体左颊的缝合疤痕流下。他的机械瞳孔在 0.2s 内从针孔状骤缩为一条竖线，右眼人类瞳孔随之收缩，嘴角牵出一个极淡的、毫无温度的笑。

【锚定特效与碰撞】：裂隙状瞳孔深处炸开一缕品红数据流，顺着义体眼眶外溢成一小片像素化残像。

### [镜头3] 2s | 液压重击：极速仰摇 ➡️ 滑动变焦 ➡️ 高速跟拍

【复合运镜】：镜头锁定机甲腾跃的躯体，背景全息广告牌因滑动变焦（Dolly Zoom）被拉成深邃的光柱隧道。随后越过机甲肩膀极速前推跟拍。

【极速动势与拆招】：机甲双腿液压缸在 0.3s 内完成蓄能，整具机体腾空三米，一体式重锤自右上斜砸而下。刀客不闪不退，反手拔刀自下而上撩出一记「逆鳞挑」，单分子刀刃在 0.1s 内横跨 40% 画面直插锤面中心。

【锚定特效与碰撞】：**重碰撞**。放射冲击帧 + 0.1s 抽帧 + 中心负片 + 镜头沿受力方向猛沉 + 三层等离子爆炸，品红与暗橙两色粒子沿锤面呈放射状炸开。

【环境反馈】：冲击力传导至桥面，直径五米的混凝土被压成凹陷，裂缝中喷出的蒸汽被瞬间抽成真空，雨幕在爆点外围形成一圈向外扩散的环形水环。

### [镜头4] 2s | 桥面贴身快打：横向同步高速跟拍 ➡️ 极高频微摇 ➡️ 轴向微震

【复合运镜】：镜头在桥面外侧超高速横向平移跟拍，伴随兵刃撞击进行极高频的左右微摇，雨滴在焦平面外被拉成连续的光条。

【极速动势与拆招】：机甲重锤回拉的同时左臂装甲板外翻，弹出三排微型弹链，在一秒内倾泻出「连、切、压、锁」四连压制。刀客义体左臂液压管爆亮，以超人体极限的频率左右格挡——第一下竖刀硬挡，第二下侧身引偏，第三下刀背下压，第四下反手挑开枪线。紧接着刀客突然变招，0.1s 内贴脸前冲，单分子刀平刺机甲核心护盖。

【锚定特效与碰撞】：**连续轻碰撞×4**。等离子黑白冲击帧 ×4 + 0.05s 抽帧 + 局部负片 + 镜头轴向高频微震，品红与暗橙粒子沿刀锋与弹链极速擦边飞溅。

【环境反馈】：被引偏的弹链击穿桥侧护栏，钢筋断口烧成暗红色，断裂的护栏段坠入下方灯河。

### [镜头5] 1.5s | 升格击穿：硬切微距 ➡️ 升格慢放 ➡️ 恢复常速

【复合运镜】：命中瞬间极速硬切至机甲核心护盖微距，画面强制升格 0.5s（绝美慢动作），随后恢复正常速度。

【极速动势与拆招】：升格画面中，单分子刀尖刺穿护盖表层，装甲金属沿刀身向两侧翻卷成银白色花状裂口，内部暗橙等离子雾从裂口猛烈外泄。机甲猛然反手一记横扫重锤砸中刀客肩部。

【锚定特效与碰撞】：**重碰撞**。放射冲击帧 + 中心负片 + 强烈的品红与暗橙粒子向后方爆炸。

【环境反馈】：刀客受力倒飞，0.3s 内横向滑退 50% 画面距离，落地时义体脚跟犁开桥面划出两道二十米长的火花沟。

### [镜头6] 1.5s | 钢缆盘旋：倒置翻转同步跟拍 ➡️ 高空俯视

【复合运镜】：镜头随刀客被击飞的抛物线同步翻转，视线短暂地走完一圈滚转，随后稳定为高空俯视。

【极速动势与拆招】：刀客在倒飞中无停顿瞬间扭腰，义体左手精准扣住桥顶斜拉的承重钢缆，借摆荡之力在半空划出半圆，双脚蹬碎桥边监控杆后借力弹回桥面中心。机甲同时启动肩部推进器，把自身重量砸向桥面制造冲击波压制。

【锚定特效与碰撞】：**轻碰撞×2**。刀客落地时等离子黑白冲击帧 + 0.05s 抽帧；机甲落地时轴向微甩。钢缆被扣住的部位爆出一串青白离子火花。

【环境反馈】：桥面中心出现蛛网式贯穿裂缝，整段桥体微微下沉并发出低频金属呻吟。

### [镜头7] 2s | 义体超载：横向拉伸机位 ➡️ 心跳频率轴向微震 ➡️ 极限透视拉伸

【复合运镜】：镜头给出横贯屏幕的巨大空间，伴随心跳频率的重低音轴向微震，威压极其恐怖窒息。

【极速动势与拆招】：刀客义体左臂的液压管集体爆亮至过曝，背部装甲板自内向外翻开！一尊由纯粹品红数据流与青白电弧构成的**巨型机械义体虚影**从雨幕中自下而上撑起，高逾三十米，双目是两枚旋转的光圈，胸前外露的液压结构随心跳节律同步搏动。它的一只巨手向下探出，指尖的像素碎片如雨般剥落。

【锚定特效与碰撞】：**无碰撞**。虚影边缘密布像素化剥落的碎块，剥落处不断滴落液态光点，被桥面雨水冲散成品红色的光溪。

### [镜头8] 2s | 只手镇压：高空俯冲爆发机位

【复合运镜】：镜头跟随这只遮天蔽日的巨手从极高空向下俯冲俯拍，空间透视拉伸到极限。

【极速动势与拆招】：虚影的巨手带着毁灭性的品红风暴从天而降，狠狠镇压向桥面中央尚未站稳的机甲。机甲将重锤高举过顶，双液压腿撑至极限硬接。

【锚定特效与碰撞】：**重碰撞**。放射冲击帧 + 0.1s 抽帧 + 中心负片 + 镜头沿受力方向猛沉 + 三层等离子爆炸。

【环境反馈】：机甲周围二十米内的桥面被气压彻底扭曲，混凝土成片粉碎下陷，下方灯河被冲击波震得集体明灭一次。

### [镜头9] 0.8s | 留白：极速推镜面罩特写

【复合运镜】：0.1s 内极速推镜至机甲驾驶舱面罩特写，强行打断动作节奏，制造暴风雨前的 0.5s 极致死寂。

【极速动势与拆招】：面罩内壁凝满水雾，驾驶员的瞳孔中倒映着遮天蔽日砸下的品红巨手与高空那张由数据流构成的冰冷面孔。机甲装甲缝隙里的暗橙等离子雾被高空压下的气流吹得彻底溃散。

【锚定特效与碰撞】：**无碰撞**。全画面只余雨声与心跳频闪的红光，0.5s 内不出现任何位移。

### [镜头10] 2s | 全屏爆发：贴地超广角 ➡️ 贴地后拉被吞没

【复合运镜】：机位死死贴附桥面，在砸中瞬间极速向后拉开。漫天尘雾以极其迅猛的速度扑面而来彻底盖过镜头。

【极速动势与拆招】：巨手轰然砸中桥面，将机甲彻底镇压吞没。巨大的烟尘与品红暗橙交织的冲击波猛然呈环形滚滚扩散，直冲云霄。

【锚定特效与碰撞】：**大招爆发**。全屏冲击帧 + 0.15s 定格抽帧 + 全屏负片闪白 + 画面径向剧烈震动 + 中心鱼眼畸变 + 环形冲击波扩散。画面被烟尘与等离子余烬彻底吞没（黑屏）。

【环境反馈】：环形冲击波将桥面两侧的护栏整段掀起，连同全息广告牌一起抛入下方车流。

### [镜头11] 2s | 完美残心：极近景侧脸跟拍 ➡️ 焦点极速转移

【复合运镜】：镜头极近景特写跟拍刀客侧脸，入鞘瞬间焦点极速转移（Rack Focus）至背景中跪趴的机甲。

【极速动势与拆招】：烟尘散开的边缘，刀客背对机甲站在桥顶边缘，风衣下摆仍在滴雨。他右手极其平稳，将单分子太刀缓慢推入背部刀鞘。

【锚定特效与碰撞】：刀身摩擦鞘口，青白离子火花在鞘口连续跳跃三次。背景中的机甲仍保持着举锤硬接的姿势，仿佛一切静止。

【音效视觉化参考】：[音效：雨声与车流声远去 ➡️ 极度清晰的"咔——"刀脊锁入鞘口的机械咬合声]

### [镜头12] 2s | 延迟爆碎：径向剧烈震荡 ➡️ 极其缓慢地向后拉推远

【复合运镜】：径向剧烈震荡 ➡️ 极其缓慢地向后拉推远。

【极速动势与拆招】：就在刀鞘锁扣发出"咔哒"轻响的瞬间，空间延迟爆发！一道极其恐怖的巨大品红刀芒，从左下至右上将机甲与身后的整段高架桥彻底撕裂。0.15s 定格抽帧 + 极致的强光泛光（Bloom）+ 鱼眼畸变。30 米高的机械义体虚影自头部开始像素化崩解。

【锚定特效与碰撞】：**大招爆发**。全屏冲击帧 + 0.15s 定格抽帧 + 全屏负片闪白 + 中心鱼眼畸变 + 环形冲击波。

【环境反馈】：这一刀不仅贯穿机甲，更将后方两根桥墩、桥面的钢筋混凝土梁以及那排全息广告牌全部一剑斜切斩断！机甲断口处的装甲剖面光滑如镜，内部液压管呈熔断状缓缓垂落，整段桥体失去支撑向灯河缓缓倾斜。远处灯河作为安谧的背景，衬托着前景被一分为二的狂暴破坏力，画面渐暗结束。
