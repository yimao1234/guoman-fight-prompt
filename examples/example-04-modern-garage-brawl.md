# 示例 04 · 现代都市 · 地下车库徒手格斗

> **验证目的**：证明这套引擎**不依赖兵器**、也不依赖古风题材。赤手空拳、现代写实场景下，同样能跑出三级碰撞与残心收尾。
> **版式**：A（块状细控版）
> **镜数**：10（合并「换地形+异象」与「残心+爆碎」两个功能位）
> **输入**：「地下车库，两个人赤手打架，写得狠一点」

## 成品

8K 3D CG 写实，PBR 物理材质，16:9 画幅，60fps，【地下三层车库，顶部管道持续滴水，应急灯以不规则频率频闪，水泥地面有一层薄薄的积尘与油膜，四周停着十几辆蒙尘轿车】，院线电影级色彩分级；湿透布料贴身产生的褶皱、皮肤毛孔与瘀青、汗珠沿下颌线滑落、发丝被汗黏在额角超写实，布料动力学真实，卫衣下摆随出拳产生真实的甩动与回弹；【黑拳手（深灰连帽卫衣，双拳缠满发黄的旧布条，赤手）】周身萦绕【死死贴附在指节与绷带缝隙上的素白汗雾与扬起的细密尘埃气流，随每次呼吸剧烈涨落】，【西装男（黑色西装外套搭在肩头，白衬衫袖口卷至小臂，领带松开，赤手）】周身萦绕【贴附在衬衫褶皱与裸露小臂上的沉黑低压气流与细密的静电裂纹，静止时近乎不可见】；人物绝对零站桩，每击皆在超高速闪转腾挪与地形穿梭中完成，拖拽极浓的汗雾与尘埃残影；全招式叠加扬尘与油膜飞溅，无悬浮光污染；全程强动态模糊 + Time Ramp（快慢镜头结合）；兵刃与肢体碰撞强制匹配三级固定特效：轻碰撞 = 尘埃黑白冲击帧 + 0.05s 抽帧 + 局部负片 + 轴向微甩，重碰撞 = 放射冲击帧 + 0.1s 抽帧 + 中心负片 + 受力猛沉 / 回弹 + 三层尘雾爆炸，大招爆发 = 全屏冲击帧 + 0.15s 定格抽帧 + 全屏负片闪白 + 中心鱼眼畸变 + 强光泛光 (Bloom) + 环形冲击波；采用 3A 动作游戏惯性追尾机位，运镜必须伴随物理动作高频变焦变速；全程纯画面输出。

### 镜头1（近景·追尾低机位·车库起手）

【核心动作】：黑拳手倒退着在积尘地面上滑出两步，双拳垂在身侧，肩胛随呼吸起伏。西装男站在两根承重柱之间，领带被车库里穿堂的冷风吹起一角。两人相距六米，中间是一辆蒙尘的灰色轿车。拳手右脚无意识地在地上碾了一下，把脚下的油膜蹭出一道亮痕。

【运镜细化】：低机位越肩，从拳手右肩后方看向西装男，机位随角色的呼吸做极轻微的上下浮动，应急灯的频闪把两人的影子在墙上反复拉长又压短。

【碰撞等级】：无。

【环境反馈】：顶部管道滴水砸在轿车引擎盖上，声音在空旷车库里被放大成钝响。

【特效叠加】：素白汗雾从拳手指节缝隙缓缓渗出；西装男小臂上的沉黑气流几乎不可见，只在应急灯闪过的半帧里显形。

### 镜头2（极近景特写·推镜面部·眼神冷掉）

【核心动作】：镜头上摇切至拳手面部特写。他松开紧咬的后槽牙，嘴角的血沿下颌线滑到下巴尖，然后极缓慢地垂下眼睑，再睁开——眼神里的那点"想谈"彻底没有了。

【运镜细化】：极近景面部定格，打断前一秒的僵持，带来极强的视觉侵略性。

【碰撞等级】：无。

【环境反馈】：无。

【特效叠加】：他呼出的白雾在应急灯下被照得清清楚楚，随即散成一片尘埃旋涡。

### 镜头3（中景·横向同步跟拍·开局重击）

【核心动作】：拳手踏碎脚下一小块水泥浮浆，0.1s 内横跨 40% 画面直冲而上。他压低重心，右腿蹬地拧腰，打出一记几乎贴着轿车引擎盖飞过去的「前手直拳」。西装男不退，前臂横在面门前硬架，同时左脚暗踩半步抢入内围。

【运镜细化】：镜头贴着轿车侧面高速横向同步平移，在拳头接触前臂的瞬间沿受力方向向侧下方猛沉并回弹。

【碰撞等级】：重碰撞。放射冲击帧 + 0.1s 抽帧 + 中心负片 + 镜头沿受力方向猛沉 / 回弹 + 三层尘雾爆炸。

【环境反馈】：冲击力传导至轿车，引擎盖被拳风压出一个浅坑，车顶积攒的厚灰被震成一团腾起的尘云。

【特效叠加】：素白汗雾与沉黑气流在两人前臂相接处对撞，炸出一圈向外翻卷的尘雾环。

### 镜头4（中景切特写·极高频微摇·贴身死斗）

【核心动作】：拳手不收拳，直接以拳变肘，一秒内倾泻出「刺、摆、挑、撞」四连快攻。西装男左臂连续内旋格开来拳，第四下反手扣住拳手手腕向下压，同时右膝猛地上顶拳手小腹。拳手勉强侧胯卸掉七成力道，反手一记「反关节甩腕」撕开锁扣，紧接着转身一记「回身摆肘」扫向西装男太阳穴。西装男后仰让过，肘尖擦着他的侧脸刮过一道血痕。

【运镜细化】：镜头在两人之间的极近距离进行极高频的左右微摇，画面充满高速运动产生的汗珠残影与动态模糊。

【碰撞等级】：连续轻碰撞×4 接重碰撞。尘埃黑白冲击帧 ×4 + 0.05s 抽帧 + 局部负片 + 镜头轴向高频微震；最后一记回身摆肘触发重碰撞。

【环境反馈】：两人脚下在油膜地面上反复打滑又稳住，鞋底犁出四道交错旋纹；被撞开的轿车门凹进一块。

【特效叠加】：两色气流沿交错的拳臂极速擦边飞溅，汗珠在应急灯下炸成一圈短促的亮点。

### 镜头5（中景切极近景特写·局部微距·升格击腹）

【核心动作】：西装男借格挡的反弹力沉肩，左臂外翻锁住拳手右臂，右拳一记寸劲直入拳手肋下。拳手极限侧身，肋下中招但没倒，反手一记「上勾拳」从下往上顶中西装男下颌。

【运镜细化】：命中瞬间极速硬切至下颌受击特写，画面强制升格 0.5 秒（绝美慢动作），清晰展现西装男下颌被顶偏、颈部皮肤因惯性甩出的波纹、嘴角血沫在空气中缓慢拉长成一条细线。随后恢复正常速度，西装男受力向后倒飞。

【碰撞等级】：重碰撞。放射冲击帧 + 中心负片 + 强烈的素白与沉黑粒子向后方爆炸。

【环境反馈】：西装男倒飞 0.3s 内横向滑退 50% 画面距离，后背狠狠砸中一根承重柱，柱面的水泥被撞掉一大块。

### 镜头6（中景·垂直翻转同步跟拍·借车腾挪）

【主核心动作】：西装男顺撞柱的反作用力无停顿瞬间蹬柱回扑。拳手翻身跃上轿车车顶，脚踩在车顶上借力起跳，在半空中把西装男整个人撞翻在相邻一辆车的后挡风玻璃上，玻璃应声炸开成蛛网。

【运镜细化】：镜头随拳手的腾跃同步上翻，短暂倒置后稳定在同一水平线，死咬两人相撞的交点。

【碰撞等级】：重碰撞。放射冲击帧 + 0.1s 抽帧 + 中心负片 + 三层尘雾爆炸。

【环境反馈】：后挡风玻璃碎裂，碎粒呈环形向外喷出；车顶被踩出两个深陷的脚印；顶部管道被震断一节，水流倾泻而下形成一道水幕。

【特效叠加】：落下的水幕在两人之间形成一层不断被撕裂又重新合拢的透明帘，两色气流穿过水幕后被折成歪斜的形态。

### 镜头7（中景切近景·追尾下压·终结一击）

【核心动作】：拳手穿过水幕，压低至贴地极限，0.1s 内如瞬移般前冲贴脸，抡出一记势大力沉的「转体摆拳」直取西装男太阳穴。西装男勉强抬臂硬架——手臂被打得贴向自己脸颊。

【运镜细化】：镜头立即转为高空俯拍下压机位，随这一拳的重量同步下沉，空间透视被压扁。

【碰撞等级】：重碰撞。放射冲击帧 + 0.1s 抽帧 + 中心负片 + 镜头沿受力方向猛沉 + 三层尘雾爆炸。

【环境反馈】：西装男身后的承重柱出现一道纵向裂纹，天花板的积灰被整体震落一层。

【特效叠加】：这一拳带出的汗雾在空中滞了一瞬才散，形成一圈极短暂的白色环。

### 镜头8（极近景特写·推镜面部·留白）

【核心动作】：0.1s 内极速推镜至西装男的双眼特写。瞳孔失调，眼球轻微震颤，倒映着迎面压下的拳影与拳手咬紧的牙关。他肩上的西装外套在震动中滑落到地上，扬起的灰在光柱里慢慢飘。他小臂上那点沉黑气流被这一拳彻底打散。

【运镜细化】：极速推镜至眼部特写，强行打断动作节奏，制造暴风雨前的 0.5 秒极致死寂。

【碰撞等级】：无。

【环境反馈】：应急灯恰在此时熄灭，车库陷入 0.5 秒的近乎全黑，只剩水声。

【特效叠加】：无。

### 镜头9（贴地超广角·贴地后拉·全屏爆发）

【核心动作】：拳手在黑暗中完成最后一记自下而上的「撩拳」，整个人的重量自下往上穿过西装男的防线。

【运镜细化】：机位死死贴附地面，在命中瞬间极速向后拉开。飞扬的灰尘与水幕以极迅猛的速度扑面而来，瞬间彻底盖过镜头。

【碰撞等级】：大招爆发。全屏冲击帧 + 0.15s 定格抽帧 + 全屏负片闪白 + 画面径向剧烈震动 + 中心鱼眼畸变 + 强光泛光 (Bloom) + 环形冲击波扩散。

【环境反馈】：环形气浪把地上所有积灰与碎玻璃同时掀起，向四周炸成一层贴地扩散的尘环，撞在四面墙上折返。

【特效叠加】：应急灯在负片闪白的一瞬短暂复亮，照出空中悬浮的亿万尘粒。画面被尘与水彻底吞没（黑屏）。

### 镜头10（近景·焦点转移·残心与延迟爆碎）

【核心动作】：应急灯重新亮起时，拳手已经垂手站定，背对西装男，胸口剧烈起伏但正在快速平复。他把缠拳的旧布条一圈圈解下来，随手扔在地上。就在布条落地的瞬间，他身后那根承重柱发出一声闷响，纵向裂纹自下而上贯通整柱，天花板的整片积灰轰然塌落，把瘫坐的西装男彻底盖住。

【运镜细化】：极近景跟拍拳手侧脸，布条落地瞬间焦点极速转移（Rack Focus）至背景那根正在裂开的承重柱；随后径向剧烈震荡 ➡️ 极其缓慢地向后拉推远。

【碰撞等级】：大招爆发（延迟触发）。全屏冲击帧 + 0.15s 定格抽帧 + 全屏负片闪白 + 中心鱼眼畸变 + 环形冲击波。

【环境反馈】：承重柱贯通开裂后被自身重量折断，车库顶部的管道成排坠落，水在积尘地面上冲刷出一条条沟壑。远处车库入口透进来的那道微弱天光作为安谧的背景，衬托着前景被一分为二的狂暴破坏力，画面渐暗结束。

【特效叠加】：断落的管道口喷出的水雾在灯下形成一道彩虹色的薄幕。

【音效视觉化参考】：[音效：耳鸣般的静默 ➡️ 极度清晰的布条落地"啪"声 ➡️ 延迟的混凝土崩裂轰鸣]

## 这则示例说明了什么

1. **不依赖兵器**——三级碰撞的原组件里没有一样东西是"刃"专属的，`兵刃与肢体碰撞`本身就包含肢体。
2. **不依赖古风**——"水墨"替换为"尘埃/水雾"之后，打击感完全保留，因为真正起作用的是**负片 + 抽帧 + 鱼眼 + 冲击波**这套电影语法。
3. **"异象"功能位可以降维**——现代题材没有魔神法相，用「承重柱贯通开裂」代替"撕裂空间"，一样承担了"把战斗从人对人抬升到人对规则"的功能。
