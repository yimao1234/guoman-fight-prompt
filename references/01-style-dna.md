# 01 · 风格 DNA 拆解

对两则原始提示词（下称 **样本 A** = `7.30`，**样本 B** = `8.2`）的结构化拆解。这一节是整套引擎的立论依据：先证明它们共享同一套语法，再把语法参数化。

---

## 1. 两则样本的骨架对照

| 结构位 | 样本 A（骨伞女 × 剑女） | 样本 B（黑发剑客 × 骨伞女） |
|---|---|---|
| 技术规格 | 8K 3D CG 写实，PBR 物理材质，16:9 画幅，60帧 | 8K 3D CG 写实，PBR 物理材质，16:9 画幅，60fps |
| 环境块 | 【幽冷月光与雷暴暗影】【幽暗迷雾的东方残破祭坛】 | 【暴雨肆虐的悬崖古刹，高低落差极大，外围是翻滚的暗黑云海，闪电交加】 |
| 色彩分级 | 院线电影级色彩分级 | 院线电影级色彩分级 |
| 超写实清单 | 衣物褶皱、皮肤毛孔纹理、发丝动态、运动汗水 | 衣物褶皱、皮肤毛孔、发丝动态、雨水沾染 |
| 物理声明 | 布料动力学真实物理形变，肌肉随招式自然拉伸 | 布料动力学真实 |
| 角色气场 | 骨伞女＝极其磅礴的青色／剑女＝极其狂躁的血红色 | 剑客＝死死贴附在衣甲与剑刃上跳跃的青黑重水流与青白电弧／骨伞女＝死死贴附在伞骨与薄纱上的紫黑阴雾与惨白骨焰 |
| 特效母题 | 雾山五行分层手绘水墨特效 + 角色专属粒子 | 雾山五行手绘水墨飞白，无悬浮光污染 |
| 时间操控 | 强动态模糊 + 水墨高速速度线 | 强动态模糊 + Time Ramp（快慢镜头结合） |
| 碰撞体系 | 三级固定特效（轻/重/大招） | 三级固定特效（轻/重/大招） |
| 机位体系 | 3A 第三人称 ACT 动态追尾机位 | 3A 动作游戏惯性追尾机位 |
| 输出约束 | 无BGM、无字幕、无水印，纯画面输出 | 全程纯画面输出 |
| 分镜数 | 10 镜 | 12 镜 |
| 分镜格式 | 镜头N（景别·机位·标签）+【核心动作】【运镜细化】【碰撞等级】【环境反馈】【特效叠加】 | [镜头N] 时长 \| 标签：运镜链 ➡️ ➡️ +【复合运镜】【极速动势与拆招】【锚定特效与碰撞】 |

**结论：样本 B 是样本 A 的进化版**——加了镜时长、把运镜写成「链式递进」、把三字段收敛得更紧凑。引擎以 B 的版式为默认（版式 B），A 的字段作为可选增强（版式 A）。

## 2. 六个不变量（风格的命门）

从两则样本里各剔除题材相关物之后，剩下的公共部分就是风格本体。共六条：

### 不变量 1 · 规格必须堆满，且堆成一句话
`8K 3D CG 写实 + PBR 物理材质 + 画幅 + 帧率 + 院线电影级色彩分级 + 超写实微观清单 + 布料动力学`——七件套齐全，且写成一整行连续长句，不用换行。这行的作用是给模型**锁死渲染档次**，缺一项质感就掉一档。

### 不变量 2 · 环境必须「高落差 + 可破坏 + 有天气」
「悬崖古刹，高低落差极大」——高落差是为了让镜头有俯冲/仰摇的空间；「外围是翻滚的暗黑云海，闪电交加」——天气是为了给光源和特效找理由；残破祭坛/木质回廊/巨型铜钟——可破坏物是为了让重击有视觉后果。

### 不变量 3 · 气场是「附着的物理现象」，不是发光体
原文最见功力的一句是 `死死贴附在衣甲与剑刃上跳跃的青黑重水流与青白电弧`。它把能量做成**有质量、有运动方式、有附着对象**的东西。

- 样本 A 写法：`周身萦绕【极其磅礴的青色】可视化流动气场，气场随动作强度动态漾动`
- 样本 B 写法：`周身萦绕【死死贴附在…上跳跃的…】`

**两种写法都合法，但都必须包含「物性 + 运动方式」。** 只写「周身有青光」就是光污染，失格。

### 不变量 4 · 双色对撞
样本 A：青 vs 血红。样本 B：青黑重水流 vs 紫黑阴雾 + 惨白骨焰。
两角色的气场色**必须构成冷/暖或明/暗的对撞**，且对撞色要在碰撞特效里显式复用（`红青两色水墨粒子沿兵刃极速擦边飞溅`）。

### 不变量 5 · 三级碰撞是标准件，逐字复用
两则样本的三级特效表高度一致，只做了微调。它是整套风格里**唯一被写成「强制匹配」的部分**——原话是 `兵刃与肢体碰撞强制匹配三级固定特效`。这意味着它不是修辞，是接口。详见 `02-collision-vfx.md`。

### 不变量 6 · 对抗律：零站桩 / 无匀速 / 无对波 / 击飞必追
原文写的是一串禁令与强制：
- `人物绝对零站桩，每击皆在超高速闪转腾挪与地形穿梭中完成`
- `无匀速影视慢推拉`
- `全程高速近身实体兵刃缠斗，无隔空对波`
- `重击必击飞，击飞后无停顿瞬间追击`
- `人物每 0.2-0.3s 完成一次横向换位闪转腾挪，快进快出绝不原地僵持`

加上**位移必须双量化**：`所有位移标注精确移动秒数与画面横向占比距离`（如 `0.1s内瞬闪横跨40%画面`、`0.3s内横向滑退50%画面距离`）。

## 3. 打斗的「节奏语法」

把样本 A 的 10 镜与样本 B 的 12 镜按功能位对齐，会发现同一根曲线：

| 功能位 | 样本 A | 样本 B |
|---|---|---|
| 起手静势 | 镜头1 低机位越肩待机·开场蓄势 | 镜头1 庭院起手·贴地前推擦肩 |
| 情绪锚（脸） | 镜头2 面部特写·邪魅一笑 | 镜头9 越肩·杀机毕露（后置变体） |
| 第一记重击 | 镜头3 垂直俯冲坠落·开局重击 | 镜头2 腾空重斩 |
| 高速拆招 | 镜头4 残影瞬闪拆招（轻碰撞×3） | 镜头3 回廊死斗（轻×4 接重） |
| 升格击飞 | 镜头5 升格击飞 | 镜头5 子弹时间·截脉 |
| 换地形/爆气 | 镜头6 盘旋爆气 | 镜头4 飞檐走壁、镜头7 巨钟摆锤 |
| 撕裂空间/异象 | 镜头7 撕裂虚空 | —（样本 B 以「屋顶塌陷」代替） |
| 大招降临 | 镜头8 只手遮天 | 镜头10 单向斩杀爆发 |
| 留白特写 | 镜头9 绝望留白 | 镜头8 升格慢放压迫 |
| 全屏爆发 | 镜头10 大招轰炸·黑屏吞没 | 镜头12 延迟爆碎 |
| 残心收势 | （黑屏收） | 镜头11 完美残心·入鞘定格 |

**骨架 = 静 → 脸 → 重击 → 拆招 → 升格 → 爆气 → 异象 → 大招 → 留白 → 爆发 → 残心 → 爆碎。**

这是引擎的分镜母版，详见 `05-shot-rhythm.md`。

## 4. 语言层面的三个癖好

1. **复合运镜链**——运镜不用单个词，而是用 `➡️` 串起 2–3 个连续镜头动作：
   `贴地极速前推 ➡️ 擦肩微距 ➡️ 180度横甩`、`极速仰摇 ➡️ 滑动变焦 ➡️ 高速跟拍`。这让相机成为动作的一部分，而不是旁观者。
2. **招式必命名**——所有攻击都有中文招式名，且偏四字、动词感强：`反手斜撩`、`旋身回旋斩`、`凌空重斩`、`逆空狂劈`、`崩棍点刺`、`粘剑推挡`、`力劈华山`、`地堂平削`。命名让动作可被模型"识别"为招式而非乱挥。
3. **全大写下划线标签**——`【复合运镜】`、`【极速动势与拆招】`、`【锚定特效与碰撞】`。方括号标题是给模型的**结构提示符**，不可省略。

## 5. 从「两则样本」到「任意打斗」的蒸馏映射

| 风格元素 | 是否可替换 | 替换规则 |
|---|---|---|
| 水墨特效 | ✅ 可替换 | 换成题材对应的粒子系统（见 `06-genre-shift.md`），但保留「附着 + 拖尾 + 飞白」的行为特征 |
| 气场色彩 | ✅ 可替换 | 只要保持双色对撞即可 |
| 战场 | ✅ 可替换 | 只要满足「高落差 + 可破坏 + 有天气」 |
| 招式流派 | ✅ 可替换 | 剑/刀/伞/拳/枪/机甲均可，招式名按流派换 |
| **三级碰撞结构** | ❌ 不可替换 | 逐字保留 |
| **对抗律（零站桩等）** | ❌ 不可替换 | 逐字保留 |
| **量化表达方式** | ❌ 不可替换 | 秒数 + 画面占比 |
| **收尾残心美学** | ❌ 不可替换 | 保留（形式可变：入鞘/停手/背影/渐暗） |

**一句话记住这套风格**：*用电影级的规格，拍一场永不站桩的近身死斗，让每一次碰撞都按同一个物理定律炸开，最后以东方人的方式收势。*
