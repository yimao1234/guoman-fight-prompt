# 04 · 招式与词汇库

风格的一大半"味道"来自词汇。这一节是可直接取用的弹药库。

---

## 1. 招式命名词库

原文里每一次攻击都有名字，且**偏四字、动词感强、带物理方向**。给招式命名能让模型把动作识别为"招式"而非乱挥。

### 剑 / 刀

| 招式 | 说明 |
|---|---|
| 反手斜撩 | 自下而上大开大合的斜向斩 |
| 旋身回旋斩 | 借腰腹核心爆发力的 360° 横扫 |
| 凌空重斩 | 腾空跃起后的自上而下重砸 |
| 力劈华山 | 双手反握的高举重劈 |
| 逆空狂劈 | 违反地心引力向上狂奔中的上撩斩 |
| 地堂平削 | 贴地滑铲中的横扫，攻下盘 |
| 过肩下劈 | 借格挡反弹力跃起后的垂直下斩 |
| 平斩 | 无花哨、快到极致的水平贯穿斩 |
| 粘剑推挡 | 腕部翻转引偏对手兵刃的防守技 |
| 刺 · 撩 · 抹 · 截 | 一秒内四连快攻的剑招组合 |
| 逆鳞挑 | 由下而上挑开对手武器 |
| 断桥截 | 中段硬截打断对手连招 |

### 伞 / 棍 / 短兵

| 招式 | 说明 |
|---|---|
| 崩棍点刺 | 以短兵当作短棍，连续点刺胸腹 |
| 平刺 | 收拢兵刃后直取心口 |
| 倾斜旋转卸力 | 撑开兵刃旋转化去冲击 |
| 伞钩锁链 | 以钩部锁住地形物借力荡开 |
| 上挑挂腕 | 兵刃上挑破坏对手重心 |
| 撑伞面硬架 | 张开面状防御接下重击 |

### 拳 / 腿 / 徒手

| 招式 | 说明 |
|---|---|
| 寸劲 | 极短距离内的爆发重击 |
| 截脉 | 精确打击手腕/关节的微操技 |
| 转身侧踹 | 借旋转惯性踹中对手胸口 |
| 磕膝 | 近身膝撞 |
| 反关节锁 | 擒拿锁死关节 |
| 肘击 | 贴身短距离重击 |
| 扫堂腿 | 贴地扫腿攻下盘 |
| 贴身摔 | 借力将对手砸向地面或建筑 |

### 通用节奏词（招式的修饰）

`极速` / `大开大合` / `势大力沉` / `雷霆万钧` / `毫无花哨` / `倾泻出` / `毫不迟疑` / `极限` / `暴力` / `精准` / `迎面` / `反冲` / `贴脸`

## 2. 气场材质形容词库

气场写法 = **色彩 + 物性 + 运动方式 + 附着对象**。以下是可组合的零件。

### 物性（气场的"材质"）

| 词 | 质感 |
|---|---|
| 重水流 | 粘稠、沉重、有下坠感 |
| 阴雾 | 弥漫、侵蚀、无固定形 |
| 电弧 | 跳跃、爆裂、瞬时 |
| 骨焰 | 阴冷、无害感的冷色火 |
| 冥火 | 幽暗、宗教感 |
| 残焰 | 未燃尽的余烬 |
| 血气 | 湿热、腥气 |
| 墨雾 | 水墨扩散、晕染 |
| 煞气 | 无形威压 |
| 电弧高压水膜 | 吸附液体后形成的带电水层 |
| 等离子雾 | 科幻向的游离气体 |
| 数据流 | 赛博向的代码化能量 |

### 运动方式（气场的"动作"）

`跳跃` / `漾动` / `翻涌` / `盘旋` / `缠绕` / `贴附` / `抖振` / `拉丝` / `爆开` / `溃散` / `炸裂` / `流动` / `翻滚` / `垂落` / `滴落`

### 强度修饰

`极其磅礴的` / `极其狂躁的` / `死死贴附的` / `惨白的` / `遮天蔽日的` / `铺天盖地的`

### 组装示例

```
【骨伞女（身穿黑色半透明薄纱与银色身体链，手持白骨做骨架的纸伞）】周身萦绕【极其磅礴的青色】可视化流动气场，气场随动作强度动态漾动
```

```
【黑发剑客（暗青长袍，手持三尺直剑）】周身萦绕【死死贴附在衣甲与剑刃上跳跃的青黑重水流与青白电弧】
```

**注意第二条更好**——因为它指定了附着对象（衣甲与剑刃）和运动方式（跳跃）。

## 3. 色彩对撞配色表

两角色的气场色必须对撞。以下是可直接取用的组合（含推荐特效层）：

| 编号 | 角色 A | 角色 B | 对撞感 | 适配题材 |
|---|---|---|---|---|
| C1 | 青（磅礴流动） | 血红（狂躁） | 冷/暖正面撞 | 古武、仙侠 |
| C2 | 青黑重水流 + 青白电弧 | 紫黑阴雾 + 惨白骨焰 | 冷/腐双暗撞 | 古武、暗黑 |
| C3 | 惨白 | 猩红 | 无血色/血 | 恐怖、武侠 |
| C4 | 玄金 | 幽蓝 | 帝气/寒煞 | 仙侠、王朝 |
| C5 | 深碧 | 赭金 | 木/土 | 山林、蛮荒 |
| C6 | 电蓝 | 品红 | 霓虹对撞 | 赛博朋克 |
| C7 | 冷白 | 暗橙 | 秩序/工业 | 科幻、机甲 |
| C8 | 素白 | 沉黑 | 水墨本体 | 现代、写意 |
| C9 | 砂金 | 暗绿 | 沙暴/毒瘴 | 废土 |
| C10 | 银灰 | 暗红 | 金属/血 | 现代枪战、特工 |

**规则**：两色在**碰撞特效里的粒子飞溅必须显式复用这两个颜色**（如 `红青两色水墨粒子沿兵刃极速擦边飞溅`）。

## 4. 角色服装与武器描述模板

原文字法：`（服装材质与配色 + 手持武器）`，控制在 8–20 字。

| 类型 | 示例 |
|---|---|
| 女性武人 | 身穿黑色半透明薄纱与银色身体链，手持白骨做骨架的纸伞 |
| 女性武人（甲） | 身穿暗红色修身轻甲，手持流光长剑 |
| 男性剑客 | 暗青长袍，手持三尺直剑 |
| 男性武人 | 玄黑短打劲装，手持双持短刀 |
| 现代格斗 | 深灰连帽卫衣、拳峰缠布，赤手 |
| 赛博 | 义体左臂外露液压管，背负单分子太刀 |
| 仙侠 | 月白广袖道袍带银线云纹，手持缠雷长鞭 |

**要点**：材质（薄纱/轻甲/长袍/卫衣）+ 配色（黑色/暗红/暗青）+ 武器（含材质），三件齐全。
