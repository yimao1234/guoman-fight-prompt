# 03 · 运镜物理层

这层负责一件事：**让相机成为打斗的一部分，而不是旁观者。**

原提示词的机位体系名称：

- 样本 A：`3A第三人称ACT动态追尾机位体系`
- 样本 B：`3A动作游戏惯性追尾机位`

两者是同一个东西——**电子游戏里那种"死咬角色后脑勺、随动作甩来甩去"的相机**。它的反面就是传统影视的匀速轨道推拉。

---

## 1. 五条运镜律

### 律 1 · 追尾优先
相机默认锁死在角色身后/侧后方，跟随其高速位移。写法：
- `手持轻微跟随角色的呼吸微动`
- `镜头跟随骨伞女极速下坠`
- `镜头锁定腾空身体`
- `镜头以极低虫眼仰拍死咬飞荡轨迹`

关键词：**死咬 / 锁定 / 跟随 / 同步**。

### 律 2 · 运镜必须成链
不许用单个运镜词，必须用 `➡️` 串起 2–3 个连续镜头动作，形成一条**运镜链**：

```
贴地极速前推 ➡️ 擦肩微距 ➡️ 180度横甩
极速仰摇 ➡️ 滑动变焦 ➡️ 高速跟拍
侧面平移跟拍 ➡️ 高频焦点摇甩 ➡️ 倾斜摇拍
极低仰拍急推 ➡️ 垂直90度仰摇 ➡️ 高空俯视
超广角硬切 ➡️ 极猛烈径向震荡 ➡️ 极度动态模糊拉伸
```

### 律 3 · 相机吃力道
碰撞时相机要**同步受力**：
- `相撞瞬间沿Z轴向下猛烈沉降并骤停`
- `镜头沿受力方向猛沉/横甩回弹`
- `镜头产生高频轴向微震`
- `命中瞬间伴随镜头径向下沉`

### 律 4 · 禁止匀速
原话：`无匀速影视慢推拉`、`运镜必须伴随物理动作高频变焦变速`。

**禁止**：匀速轨道推进、缓慢摇臂、平滑稳定器长镜头、无动机的缓慢拉远。
**允许**：高速推拉（Push In / Pull Out）、硬切、骤停、瞬时变焦、随动作变速。

唯一合法的"慢"是**刻意的定格与留白**——那是节奏手段，不是运镜惯性。

### 律 5 · 构图守人
**人物占画面面积 ≥ 1/3。** 这是硬约束。

环境再宏大（遮天蔽日的魔神巨手、横贯屏幕的虚空裂缝），人物也必须撑住画面的三分之一。禁止为了炫场景把角色拍成远景中的一个小黑点——那种镜头是空镜，不是打斗。

**合规写法**：用「贴地超广角 + 人物前景占位」「越肩」「近景」等景别保证人物体量；广角镜里让角色的肢体/残影/气场仍占据前景大块面积。

| 贴地 / 虫眼 | Ground-level / Worm's eye | 极低机位，夸张空间高度 |

### 景别

极近景特写 → 特写 → 近景 → 中景 → 全景 → 贴地超广角

**用法规律**：打斗用近景/中景保人物体量；环境震撼用全景/超广角但必须给前景人物质感；情绪锚点用面部特写。

| 倾斜 | Dutch Angle | 重击、失衡 |

## 3. 位移量化写法

原话：`所有位移标注精确移动秒数与画面横向占比距离`。

**这是本风格最容易被忽略、又最见功力的一条。** 不量化，模型就不知道"快"到什么程度。

### 公式

```
[时长] 内 + [动作] + [画面占比 / 空间参照]
```

### 从原文提炼的量化句式

| 句式 | 出处 |
|---|---|
| `0.1s内瞬闪横跨40%画面逼近` | 样本 A 镜头4 |
| `0.1s内如瞬移般极速前冲贴脸` | 样本 A 镜头4 |
| `0.3s内横向滑退50%画面距离` | 样本 A 镜头5 |
| `0.1s内跨越半个庭院` | 样本 B 镜头1 |
| `身形在0.01s内化作一道贯穿屏幕的...闪电` | 样本 B 镜头10 |
| `人物每0.2-0.3s完成一次横向换位` | 样本 A 头块 |
| `一秒内倾泻出"刺、撩、抹、截"四连快攻` | 样本 B 镜头3 |
| `巨钟从鼻尖上方不足十厘米呼啸扫过` | 样本 B 镜头8 |
| `青色闪电在骨伞女身后拖拽出长达二十米的恐怖水墨残影` | 样本 B 镜头10 |

### 量化的三种尺度

| 尺度 | 单位 | 适用 |
|---|---|---|
| **时间** | 0.01s / 0.1s / 0.3s / 1s | 所有位移与招式节奏 |
| **画面占比** | 40% 画面 / 50% 画面距离 / 贯穿屏幕 | 横向位移 |
| **物理距离** | 十厘米 / 五米 / 二十米 / 半个庭院 | 贴身擦过、残影长度、招式范围 |

**至少用两种尺度描述同一段位移**（如"0.1s 内横跨 40% 画面"＝时间 + 画面占比）。

## 4. 典型镜头设计模板

| 用途 | 推荐机位组合 |
|---|---|
| **起手** | 低机位越肩待机 ➡️ 手持呼吸微动；或贴地极速前推 ➡️ 擦肩微距 ➡️ 180度横甩 |
| **对峙** | 极近景面部定格 ➡️ 眼尾炸开气场 |
| **突进** | 追尾下坠 ➡️ 沿 Z 轴猛沉骤停 |
| **贴身快打** | 横向同步高速跟拍 ➡️ 极高频左右微摇 ➡️ 轴向微震 |
| **命中定格** | 硬切至受击部位微距 ➡️ 升格 0.3–0.5s ➡️ 恢复常速击飞 |
| **腾空 / 爆气** | 同步腾空 ➡️ 视线被雾气遮蔽 ➡️ 高空俯视 |
| **异象降临** | 横向拉伸机位 ➡️ 心跳频率轴向微震 ➡️ 极限透视拉伸 |
| **大招前留白** | 匀速推镜面部特写 ➡️ 0.5s 死寂（节奏手段，非运镜惯性） |
| **终结** | 超广角硬切 ➡️ 径向剧烈震荡 ➡️ 极度动态模糊拉伸 |
| **残心** | 极近景侧脸跟拍 ➡️ 焦点极速转移至背景对手 |
