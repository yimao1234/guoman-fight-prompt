**骨架不动，只换皮。** 三级碰撞、对抗律、量化表达、残心收尾四项在任何题材下都逐字保留；换的是「特效材质 / 气场物性 / 破坏物 / 光源 / 招式流派」。

> **校园/日常题材的适配提示**：三级碰撞特效里的"水墨"可替换为"水花/尘粒/碎屑"，但**组件数量与抽帧时长必须完全一致**（轻=5件 / 重=5件 / 大招=6件）。这是保持打击感统一的关键。

## 特效材质替换对照（核心动作）

| 原组件 | 古武 | 现代 | 科幻 | 赛博 |
|---|---|---|---|---|
| 水墨黑白冲击帧 | 水墨黑白冲击帧 | 水花黑白冲击帧 | 等离子黑白冲击帧 | 像素黑白冲击帧 |
| 局部/中心负片 | 同 | 同 | 同 | 同 |
| 三层水墨粒子爆炸 | 三层墨雾爆炸 | 三层水雾爆炸 | 三层等离子爆炸 | 三层数据碎片爆炸 |
| 全屏负片闪白 | 同 | 同 | 同 + 泛光 | 同 + 色散 |
| 中心鱼眼畸变 | 同 | 同 | 同 | 同 + 扫描线 |
| 环形冲击波 | 水墨环形波 | 水浪环形波 | 电磁环形波 | 冲击环 + 数据涟漪 |

**不可替换的组件**：负片、抽帧、鱼眼畸变、径向震荡、泛光、环形冲击波——这些是**电影语法**，与题材无关。

## 一个判断口诀

拿到任何题材，问四个问题：

1. **他们的能量贴在哪？**（衣甲 / 武器 / 义体 / 皮肤）→ 决定气场写法
2. **砸坏什么最有说服力？**（木栏 / 玻璃 / 舱壁 / 课桌）→ 决定环境反馈
3. **光从哪来？**（月光 / 霓虹 / 警报灯 / 天窗）→ 决定色彩分级方向
4. **收招的仪式动作是什么？**（入鞘 / 收刀 / 关机 / 垂手）→ 决定残心美学

答完这四个问题，套模板就能出片。
