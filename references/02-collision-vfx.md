# 02 · 三级碰撞特效矩阵

这是整套风格的**引擎核心**，也是唯一被原提示词写成「强制匹配」的接口。

> 原文：`兵刃与肢体碰撞强制匹配三级固定特效`

含义：**每一次碰撞都必须先判定等级，再挂载该等级的固定特效组。** 不许自创等级，不许混搭组件，不许漏项。

---

## 1. 标准件全文（照抄使用）

### 轻碰撞

```
水墨黑白冲击帧 + 0.05s抽帧 + 局部负片 + 镜头轴向微甩 + 粒子飞溅
```

| 组件 | 作用 |
|---|---|
| 水墨黑白冲击帧 | 单帧黑白化的水墨状爆点，标记接触点 |
| 0.05s 抽帧 | 极短卡顿，制造"脆"的手感 |
| 局部负片 | 只反色接触点附近，保留画面其余部分 |
| 镜头轴向微甩 | 相机沿受击轴轻抖，传递力道 |
| 粒子飞溅 | 两色粒子的擦边飞溅（按角色配色） |

**触发场景**：兵刃格挡、快攻连击、擦边、点刺、卸力。一次镜头内可连发（`连续轻碰撞×3`、`连续轻碰撞×4`）。

### 重碰撞

```
水墨放射冲击帧 + 0.1s抽帧 + 中心负片 + 镜头沿受力方向猛沉/横甩回弹 + 三层水墨粒子爆炸
```

| 组件 | 作用 |
|---|---|
| 水墨放射冲击帧 | 放射状水墨爆开，方向感明确 |
| 0.1s 抽帧 | 比轻碰撞长一倍，制造"沉"的手感 |
| 中心负片 | 反色区域集中在画面中心 |
| 镜头猛沉/横甩回弹 | 相机沿受力方向下坠或横甩后回弹 |
| 三层水墨粒子爆炸 | 内/中/外三层不同速度的粒子，产生体积感 |

**触发场景**：重斩砸中、击飞命中、架住重击、撞碎梁柱。

### 大招爆发

```
全屏水墨冲击帧 + 0.15s定格抽帧 + 全屏负片闪白 + 径向剧烈震动 + 中心鱼眼畸变 + 环形冲击波扩散
```

| 组件 | 作用 |
|---|---|
| 全屏水墨冲击帧 | 整屏被水墨填满，无死角 |
| 0.15s 定格抽帧 | 最长的卡顿，定格成"传奇瞬间" |
| 全屏负片闪白 | 全画面反色 + 瞬时过曝 |
| 径向剧烈震动 | Radial Shake，从中心向外炸裂 |
| 中心鱼眼畸变 | 中心凸起/凹陷，空间被撕裂 |
| 环形冲击波扩散 | 冲击波呈环形向外推进，扫过环境 |

**触发场景**：终结技、必杀、法相镇压、单向斩杀。**全片仅 1–2 次**，用滥则不值钱。

## 2. 抽帧时间表

原提示词的抽帧时长不是随便写的，它和碰撞等级强绑定：

| 等级 | 抽帧时长 | 定格感 | 出现频次 |
|---|---|---|---|
| 轻碰撞 | 0.05s | 几乎察觉不到的"卡" | 高频，每镜可多次 |
| 重碰撞 | 0.10s | 明显的一顿 | 中频，每 1–2 镜一次 |
| 大招爆发 | 0.15s | 完全定格 | 全片 1–2 次 |

**配套的时间操控**（非抽帧类）：

| 手法 | 时长 | 用途 |
|---|---|---|
| 升格慢动作 | 0.3–0.5s | 命中瞬间的"绝美慢镜"，展现形变细节 |
| 子弹时间 | 0.2s | 局部微操（如手指截脉），强调精确 |
| Time Ramp | 整段 | 快 → 慢 → 快的速度曲线，用于大招冲刺 |
| 定格抽帧 | 0.15s | 大招收束的"传奇定格" |

## 4. 特效的「附着律」

原提示词反复强调特效不能悬浮：

- `死死贴附在衣甲与剑刃上跳跃的青黑重水流与青白电弧`
- `无悬浮光污染`
- `剑身吸附积水形成电弧高压水膜`
- `指甲犹如苍白的利刃，边缘带有浓重的青色飞白水墨`
- `裂缝处不断滴落黑色的墨滴`

**判定标准**：每一条特效描述都要能回答「它贴在哪」。

| 失格写法 | 合格写法 |
|---|---|
| 周身有青光 | 淡青气流贴着她的薄纱下摆持续抖振 |
| 剑上附着紫色能量 | 紫黑阴雾缠绕伞骨，随开合动作在骨节间跳跃 |
| 打斗时有火焰 | 血焰粒子沿剑刃走向飞溅，落点在地面烧出焦痕 |

**特效三律：附着（贴在什么上）+ 运动（怎么动）+ 残留（留下什么）。** 三者齐备即为合格描述。

## 5. 碰撞的「环境反馈」配套

重碰撞与大招**必须**给出环境后果，否则打击感落空。原文示例：

- `巨大冲击力传导至地面，石板瞬间大面积凹陷龟裂，积水震碎成雾`
- `下方的空间已被庞大的气压彻底扭曲，剑女周围的废墟开始大面积粉碎下陷`
- `最后一记重斩直接砸碎木质护栏，木屑横飞`
- `恐怖的重压让屋脊主梁断裂，整个屋顶塌陷`
- `铜锈与雨水被气浪呈环形震飞`
- `这道青黑水墨剑罡不仅撕裂了骨伞女，更将后方大殿残存的木质承重柱、地面的青石板以及那口砸落的巨型铜钟全部一剑斜切斩断`

**写法公式**：`冲击力 → 传导对象 → 形变结果 → 二次产物（碎屑/尘雾/水花）`

例：`冲击力传导至地面 → 青石板 → 大面积凹陷龟裂 → 积水震碎成雾`
