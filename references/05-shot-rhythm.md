# 05 · 分镜节奏曲线

这套风格的分镜不是随便切，而是**按功能位推进的固定曲线**。把两则样本对齐后，得到 12 个功能位。

**核心原则：功能位不能少，镜数可增减。**

- 要更紧凑 → 合并「腾空爆气 + 撕裂空间」，压到 10 镜
- 要更完整 → 在「高速拆招」位展开成 2–3 镜，扩到 14 镜

---

## 12 镜母版

### 镜头 1 · 起手静势
| 项 | 内容 |
|---|---|
| 功能 | 建立空间、人物关系与压迫感。全片唯一的"静" |
| 时长 | 1–1.5s |
| 机位 | 低机位越肩待机（+手持呼吸微动）／贴地极速前推 ➡️ 擦肩微距 ➡️ 180度横甩 |
| 必写 | 角色的**待机姿态**（蹲踞石柱顶／脚踏水膜压至贴地极限）+ 气场首次亮相 |
| 禁忌 | 不许把相机架在远处慢慢推——要么静止带呼吸，要么直接极速推近 |

> 样本 A：`骨伞女如幽灵般单脚蹲踞在祭坛最高处的残破石柱顶端，肩上撑着惨白的骨伞…周身萦绕着如丝带般缓缓流动的青色水墨气场`

### 镜头 2 · 情绪锚（脸）
| 项 | 内容 |
|---|---|
| 功能 | 用一张脸定掉这场戏的性格。**最短、最贵的一镜** |
| 时长 | 0.8–1s |
| 机位 | 极近景面部定格／推镜面部快切 |
| 必写 | 一个**微表情**（邪魅一笑／眼神爆燃／眼底一闪）+ 面部边缘的气场反应 |
| 效果 | 打断前一秒的静谧，带来极强的视觉侵略性 |

> 样本 A：`她微微低头，透过伞檐的阴影对着镜头下方露出一抹极具挑衅、慵懒且危险的"邪魅一笑"，眼尾瞬间炸开一缕青色水墨`

### 镜头 3 · 第一记重击
| 项 | 内容 |
|---|---|
| 功能 | 开场即重锤，告诉观众"这不是试探" |
| 时长 | 1.5–2s |
| 机位 | 垂直俯冲坠落追尾／极速仰摇 ➡️ 滑动变焦 ➡️ 高速跟拍 |
| 必写 | 双方的**迎击动作**（不是单方面挨打）+ 针尖对麦芒式的接触点 |
| 碰撞 | **重碰撞**（首次挂载三级特效） |
| 环境 | 首处破坏（石板凹陷龟裂／水膜震碎成雾） |

### 镜头 4 · 高速拆招
| 项 | 内容 |
|---|---|
| 功能 | 全片最"爽"的一段——速度与情报密度的峰值 |
| 时长 | 1.5–2s（可拆成 2–3 镜） |
| 机位 | 横向同步高速跟拍 ➡️ 极高频率左右微摇 ➡️ 轴向微震 |
| 必写 | **一套完整攻防**：攻方出招 → 守方化解 → 守方反打 → 攻方变招。四个节拍不许省 |
| 位移 | 每 0.2–0.3s 一次横向换位，全部带双量化 |
| 碰撞 | **连续轻碰撞 ×3~4** |

> 样本 B：`长剑在一秒内倾泻出"刺、撩、抹、截"四连快攻！骨伞女手中骨伞左右极速倾斜、竖架死死挡住。剑客突然变招…`

### 镜头 5 · 升格击飞
| 项 | 内容 |
|---|---|
| 功能 | 第一次打破常速。用慢镜放大"命中的质量" |
| 时长 | 1.5s |
| 机位 | 硬切至受击部位微距 ➡️ 升格 0.3–0.5s ➡️ 恢复常速 |
| 必写 | 受击部位的**形变细节**（轻甲凹陷、气场被踹碎、面部扭曲） |
| 结果 | **击飞**，并量化（`0.3s内横向滑退50%画面距离`） |
| 碰撞 | **重碰撞** |

### 镜头 6 · 换地形 / 爆气
| 项 | 内容 |
|---|---|
| 功能 | 把战场从 A 点搬到 B 点，同时给下一段升级一个理由 |
| 时长 | 1–1.5s |
| 玩法 | ① 顺反作用力腾空（无停顿瞬间起身）② 沿木柱垂直狂奔 ③ 钩住铁链荡开半圆 ④ 武器脱手盘旋 |
| 必写 | 位移路径 + 地形交互（踩碎什么、钩住什么、荡向哪里） |

> 样本 B：`骨伞女被重斩砸退，伞柄反手挂住上方的飞檐翘角飞荡而上。剑客双脚踩上回廊垂直的承重木柱，违反地心引力全速向上狂奔`

### 镜头 7 · 撕裂空间 / 异象
| 项 | 内容 |
|---|---|
| 功能 | 把战斗从"人对人"抬升到"人对规则"。威压峰值之一 |
| 时长 | 1.5–2s |
| 机位 | 横向拉伸机位 ➡️ 心跳频率轴向微震 ➡️ 极限透视拉伸 |
| 必写 | 一个**超出人体尺度的存在**登场（魔神巨手／法相／机神／巨大构造体），并给出它的**探出 / 撕开 / 撑破**动作 |
| 细节 | 异象的边缘材质（指甲如苍白利刃、边缘带青色飞白水墨、裂缝滴落墨滴） |

> 样本 A：`两只极其巨大、布满青色咒文的暗黑色魔神巨手一上一下猛然探出，死死抠住裂缝边缘，向上下两侧暴力撕开一道横贯整个屏幕的巨大虚空裂缝`

### 镜头 8 · 大招降临
| 项 | 内容 |
|---|---|
| 功能 | 把镜头 7 的威压兑现成物理打击 |
| 时长 | 1.5–2s |
| 机位 | 高空俯冲爆发机位 ➡️ 跟随巨物向下俯拍 ➡️ 空间透视拉伸到极限 |
| 必写 | 巨物的**下压轨迹** + 地面上另一方的**应对或无力应对** |
| 环境 | 空间被气压扭曲，周围建筑大面积粉碎下陷 |

### 镜头 9 · 留白特写
| 项 | 内容 |
|---|---|
| 功能 | **全片最重要的节奏手段。** 大招落地前插入死寂 |
| 时长 | 0.5–1s |
| 机位 | 极速推镜至眼部特写（景别上属于"匀速推镜"，是唯一合法例外） |
| 必写 | 绝望/惊愕/凛然的**眼神倒影**（倒映着遮天蔽日的巨手与白骨面具）+ 气场被气流吹散 |
| 效果 | `强行打断动作节奏，制造暴风雨前的0.5秒极致死寂` |

### 镜头 10 · 全屏爆发
| 项 | 内容 |
|---|---|
| 功能 | 大招兑付。全片唯一的"全屏级"事件 |
| 时长 | 1.5–2s |
| 机位 | 贴地超广角 ➡️ 贴地后拉被吞没 |
| 碰撞 | **大招爆发**（唯一挂载全屏特效组的一镜） |
| 收束 | 环形冲击波扩散 + 画面被烟尘/能量彻底吞没（黑屏） |
| 环境 | 环形破坏，直冲云霄 |

### 镜头 11 · 残心收势
| 项 | 内容 |
|---|---|
| 功能 | **东方美学本体**。打完不吼不叫，用一个静止动作收掉全场 |
| 时长 | 1.5–2s |
| 机位 | 极近景特写跟拍侧脸 ➡️ 焦点极速转移（Rack Focus）至背景对手 |
| 必写 | 一个**仪式化动作**：缓慢推剑入鞘／收伞／垂手／背对站立 |
| 细节 | 手上动作的物理细节（剑刃摩擦鞘口、电弧跳跃）+ 背景对手**保持扑杀姿势凝固不动** |
| 音效 | 只允许写成视觉化参考：`【音效视觉化参考】：暴雨声远去 ➡️ 极度清晰的"铮——"剑刃摩擦入鞘声` |

### 镜头 12 · 延迟爆碎
| 项 | 内容 |
|---|---|
| 功能 | 把"静止"的势能一次性释放。全片最强的一击其实发生在收招之后 |
| 时长 | 1.5–2s |
| 触发 | 用一个小动作当扳机（剑格闭合的"咔哒"轻响／伞骨合拢） |
| 机位 | 径向剧烈震荡 ➡️ 极其缓慢地向后拉推远（此处的"慢"是终章语汇，合法） |
| 碰撞 | **大招爆发**（第二次，也是最后一次） |
| 破坏 | 一道巨大斩击/冲击将背景建筑彻底撕裂，斜切贯穿承重结构 |
| 收尾 | 远景安谧背景（云海/雨幕/霓虹）衬托前景狂暴破坏，**画面渐暗结束** |

## 节奏曲线可视化

```
强度
 ▲
 │                    ┌── 镜头10 全屏爆发
 │            ┌── 7,8 ┘
 │      ┌─ 5 ─┤                    ┌── 镜头12 延迟爆碎（真正的终结）
 │  ┌ 3 ┤     └─ 6                 │
 │  │   └ 4                    ┌ 11┘
 │ 1┘              镜头9 留白 ──┘
 └──────────────────────────────────────────► 时间
   静  锚  重  速  升  换  异  大  白  爆  收  碎
```

**两个必须存在的低谷**：镜头 1（开场静）与镜头 9（大招前留白）。没有低谷，高潮就不值钱。

## 镜数压缩 / 扩展规则

| 目标镜数 | 操作 |
|---|---|
| 8 镜 | 合并 6+7（换地形时直接撕裂空间）；合并 11+12（收势同时爆碎） |
| 10 镜 | 合并 6+7 |
| 12 镜 | 母版 |
| 14 镜 | 把镜头 4 拆成 2 镜（近身快打 + 变招重击）；把镜头 9 前后各加一镜过渡 |
